# Part V: Language Models

From n-grams to reasoning models. You will write a tokenizer and a GPT from scratch, then learn how the big ones are pretrained, served, fine-tuned and aligned.

About 175 hours in total.

| Module | Hours | What it's about |
|---|---|---|
| [34. Classical NLP](34-classical-nlp/) | 25 | The ideas that came before transformers, and still run half of the text processing in the world. |
| [35. Building an LLM](35-building-an-llm/) | 50 | The whole stack of a decoder-only language model, minus the hundred million dollars. |
| [36. Encoders and Encoder-Decoders](36-encoders/) | 15 | The models that quietly power search, classification and extraction everywhere. |
| [37. Inference](37-inference/) | 25 | Training happens once. Inference happens every time a user types something. That's where the money goes. |
| [38. Post-Training](38-post-training/) | 40 | How a text predictor becomes an assistant, and how assistants learned to reason. |
| [39. Evaluating and Extending LLMs](39-evaluating-extending-llms/) | 20 | How to tell if a model is good, and how models learned to see and hear. |
