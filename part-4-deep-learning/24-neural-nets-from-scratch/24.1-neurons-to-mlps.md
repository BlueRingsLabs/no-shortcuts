## The neuron and the layer

A **unit** (neuron) computes an affine function of its inputs and passes it through a nonlinearity: $h = \phi(w^\top x + b)$. A **layer** does this for many units at once: $h = \phi(Wx + b)$, with $W$ of shape
(units × inputs), and $\phi$ applied elementwise. For a batch of inputs stacked as rows of $X$: $H = \phi(XW^\top + b)$, one matrix multiplication (07.3 explains why that's the fast way).

A **multilayer perceptron** (MLP, or fully connected / dense network) stacks layers:

$$h^{(1)} = \phi(W^{(1)}x + b^{(1)}), \quad h^{(2)} = \phi(W^{(2)}h^{(1)} + b^{(2)}), \quad \dots, \quad \hat y = g(W^{(L)}h^{(L-1)} + b^{(L)})$$

with an **output function** $g$ matched to the task and loss: identity with squared error for regression, sigmoid with binary cross-entropy, softmax with categorical cross-entropy (17.3, 17.4). The number of
parameters is $\sum_\ell (n_{\ell-1} + 1)\,n_\ell$; a 784-256-128-10 network (MNIST-sized) has about 235,000.

The name "neuron" is historical (McCulloch and Pitts, 1943; Rosenblatt's perceptron, 1958). A real neuron is vastly more complicated, and the analogy has caused more confusion than insight. Think "differentiable
function composed of simple pieces" and you'll reason better.

## Why the nonlinearity is essential

The module's self-check. Remove $\phi$ and each layer is affine; a composition of affine maps is affine (02.2): $W^{(2)}(W^{(1)}x + b^{(1)}) + b^{(2)} = (W^{(2)}W^{(1)})x + (W^{(2)}b^{(1)} + b^{(2)})$. A hundred linear layers are exactly one linear layer,
with a lot of redundant parameters. It still can't do XOR, and it's still logistic regression at the end. The lab multiplies out a five-layer linear network and gets the same predictions from a single matrix.

The nonlinearity is what lets each layer bend space, so that the next layer can cut it with a hyperplane. Everything a deep network can do that a linear model can't comes from it.

## Activation functions

| Activation | $\phi(z)$ | $\phi'(z)$ | Notes |
|---|---|---|---|
| Sigmoid | $\frac{1}{1 + e^{-z}}$ | $\phi(1 - \phi) \le 0.25$ | Saturates at both ends; gradients vanish through many layers. Now used only as an output or a gate. |
| Tanh | $\tanh z$ | $1 - \phi^2 \le 1$ | Zero-centered sigmoid; still saturates. Used in RNN gates (28.2). |
| ReLU | $\max(0, z)$ | 0 or 1 | Cheap, no saturation for $z > 0$, sparse activations. Units stuck at $z < 0$ for all inputs are **dead** and stop learning. The default for years. |
| Leaky ReLU | $\max(\alpha z, z)$ | $\alpha$ or 1 | Small slope for $z < 0$ keeps gradients alive. |
| GELU | $z\,\Phi(z)$ | smooth | A smooth ReLU; standard in transformers (29.2). |
| SiLU / Swish | $z\,\sigma(z)$ | smooth | Similar to GELU; in SwiGLU feed-forward blocks of modern LLMs (35.5). |

Why saturation matters: backpropagation (24.2) multiplies derivatives layer by layer. With sigmoids, each factor is at most 0.25, so after ten layers the gradient at the bottom is at most $0.25^{10} \approx 10^{-6}$ of
the one at the top: the **vanishing gradient** problem that kept deep networks untrainable until ReLUs, better initialization (26.2), normalization and residual connections (26.4). The lab measures it.

## What an MLP can represent

**Universal approximation** (Cybenko, 1989; Hornik, Stinchcombe and White, 1989; Leshno et al., 1993 for any non-polynomial activation): a network with *one* hidden layer and enough units can approximate any continuous
function on a compact set to any accuracy. Comforting and nearly useless in practice, because it says nothing about:

- **How many units**: possibly astronomically many.
- **Whether gradient descent will find the weights.**
- **Whether the result will generalize** from finite data (16.2).

A ReLU network makes the representation concrete: it computes a **piecewise-linear** function (each ReLU contributes a kink). You can build one by hand that linearly interpolates any 1-D function between
$N$ knots with $N$ hidden units, with error shrinking like $1/N^2$ for smooth functions; the lab does it for a sine wave, no training involved.

**Why depth?** Width alone is universal, so why stack layers? Because some functions are exponentially cheaper to represent deep. Compose the "tent" map (two ReLUs) with itself $k$ times and you get a sawtooth
with $2^k$ linear pieces, using $2k$ units in $k$ layers; a single hidden layer needs about $2^k$ units to make that many kinks (Telgarsky, 2016). Depth reuses computation: each layer folds the space, and the next
layer's features are defined on the folded space. The lab builds the sawtooth and counts its pieces. A caution the lab also shows: that's the *worst case*. A randomly initialized deep
network has about as many pieces as a shallow one with the same number of units (Hanin and Rolnick, 2019); depth makes the complex functions *reachable*, and training has to find them. Real data (images, language) has this kind of compositional, hierarchical structure (edges → textures →
parts → objects), which is the best informal argument for why depth helps.

> **Scar tissue.** My first neural network from scratch, for a university assignment, had a loss curve that went down, then up, then down,
> in long regular waves. I tuned the learning rate for a day. The training data was sorted by class, and I iterated over it in order, so
> the network spent each stretch of an epoch learning that everything was a zero, then that everything was a one. Shuffling fixed it in
> one line. The day of tuning taught me to look at the data before the optimizer.

## Things that will bite you

- **Forgetting the nonlinearity** (or putting it after the last layer when the loss expects logits, 17.4).
- **Sigmoid hidden layers** in a deep network.
- **Dead ReLUs** from a bad initialization or a learning rate that's too high (26.2).
- **Reading "universal approximation"** as "any MLP will learn anything".
- **Counting parameters** as a measure of capacity (16.3, double descent).

## Exercises

1. Show that a network of linear layers of any depth is equivalent to a single linear layer. What's the rank of the combined map if one of the hidden layers is narrower than the input?
2. Build by hand a one-hidden-layer ReLU network (weights and biases) that computes $|x|$ exactly. And one that computes $\max(x_1, x_2)$.
3. Compute the number of parameters of a 100-512-512-10 MLP.
4. Why does the gradient through $L$ sigmoid layers vanish? Give a bound on the product of derivatives.
5. The tent map $t(x) = 2\,\text{ReLU}(x) - 4\,\text{ReLU}(x - 0.5)$ on $[0, 1]$. How many linear pieces does $t \circ t \circ t$ have? How many units does it take as a deep network, and as a shallow one?

<summary>Answers</summary>

1. Each layer is $x \mapsto Wx + b$; composing two gives $(W_2W_1)x + (W_2b_1 + b_2)$, still affine; induct on depth. The combined matrix $W_L\cdots W_1$ has rank at most the smallest layer width, so a narrow linear
   hidden layer is a bottleneck that *reduces* what a linear model can represent (this is linear PCA-style compression, 21.3).

2. $|x| = \text{ReLU}(x) + \text{ReLU}(-x)$: two hidden units with weights $+1, -1$, output weights $1, 1$. $\max(x_1, x_2) = x_2 + \text{ReLU}(x_1 - x_2)$, and $x_2 = \text{ReLU}(x_2) - \text{ReLU}(-x_2)$: three hidden units (inputs $x_1 - x_2$, $x_2$, $-x_2$),
   output weights $1, 1, -1$.

3. $(100 + 1) \cdot 512 + (512 + 1) \cdot 512 + (512 + 1) \cdot 10 = 51{,}712 + 262{,}656 + 5{,}130 = 319{,}498$.

4. Backprop multiplies, per layer, by $\sigma'(z) \le 1/4$ and by a weight matrix. With weights of moderate size, the product of $L$ factors is at most about $(\|W\|/4)^L$, which shrinks exponentially in $L$ unless the weights are large,
   and large weights push units into saturation where $\sigma'$ is near 0. Either way, the bottom layers get tiny gradients.

5. Each application of the tent doubles the number of linear pieces: 2, 4, 8. So 8 pieces. Deep: 2 units per layer, 3 layers, 6 units. Shallow: a one-hidden-layer ReLU network with $u$ units has at most $u + 1$ pieces
   in 1-D, so it needs at least 7 units; for $k$ compositions, $2k$ deep units vs about $2^k$ shallow ones.
