# 32.1 Message passing and GNNs

*About 10 hours. Prerequisites: 02.2 (matrices), 21.4 (neighbor graphs and spectral embeddings, helpful), 26.4 (residuals), 29.1 (attention). Lab: [`lab_32_1_message_passing.py`](labs/lab_32_1_message_passing.py).*

Some data is a network: users who follow users, accounts that send money to accounts, hosts that talk to hosts, atoms bonded to atoms,
papers citing papers, roads joining junctions. You can flatten it into a table (degree, PageRank, counts of neighbors with some property)
and feed a gradient-boosted model, and you should try that first (Part III). **Graph neural networks** learn from the structure directly:
each node's representation is computed from its own features and its neighbors', and stacking layers lets information travel along paths.

For the security-minded: fraud rings, bot networks, lateral movement, money-mule chains and malicious domains that share infrastructure are all
graph problems, and "guilt by association" is exactly what a GNN learns. So is the associated false positive rate on the innocent neighbor,
which you'll want to measure.

## Message passing

A graph has nodes $v$ with feature vectors $x_v$ and edges (possibly with features). A **message passing** layer (Gilmer et al., 2017) updates every node from its neighborhood $\mathcal{N}(v)$:

$$h_v' = \phi\left(h_v,\; \bigoplus_{u \in \mathcal{N}(v)} \psi(h_v, h_u, e_{uv})\right),$$

where $\psi$ computes a message from each neighbor, $\bigoplus$ is a **permutation-invariant** aggregator (sum, mean, max), and $\phi$ updates the node. Because the aggregator doesn't care about the order of neighbors, the whole layer is **permutation equivariant**: renumber the nodes and the outputs are renumbered the same way (the lab checks it), which is what you want, since node IDs are arbitrary. After $k$ layers, each node's representation depends on its $k$-hop neighborhood.

The architectures differ in their choices:

- **GCN** (Kipf and Welling, 2017): $H' = \sigma(\hat A H W)$, with $\hat A = \tilde D^{-1/2}(A + I)\tilde D^{-1/2}$: add self-loops, normalize symmetrically by degree, and each node becomes a weighted average of itself and its neighbors, after a shared linear map. Simple, fast (a sparse matrix product per layer), and the baseline everything is compared with. It comes from spectral graph theory (a first-order approximation of a graph convolution), which you don't need in order to use it.
- **GraphSAGE** (Hamilton, Ying and Leskovec, 2017): $h_v' = \sigma(W_1 h_v + W_2 \cdot \text{agg}(\{h_u\}))$, keeping the node's own features separate from the neighborhood summary; and **neighbor sampling**, which trains on large graphs by sampling a fixed number of neighbors per node per layer instead of using all of them. It's also **inductive**: it applies to nodes and graphs not seen during training, where the original GCN was framed transductively.
- **GAT** (Veličković et al., 2018): weights neighbors with **attention** (29.1), so a node can learn which neighbors matter. A transformer is a GAT on a complete graph, with positional encodings (29.3) standing in for structure.
- **GIN** (Xu et al., 2019): sum aggregation plus an MLP, as expressive as the Weisfeiler-Lehman graph isomorphism test, which is the upper bound for this family (below).

## Tasks

- **Node classification**: label some nodes, predict the rest (fraud accounts, paper topics). Often **semi-supervised**: the whole graph is available, few labels.
- **Link prediction**: will these two nodes connect? (recommendations, 23.2; knowledge graph completion; predicting drug interactions). Score pairs of node embeddings; evaluate with care, since the removed test edges must not leak through the training graph.
- **Graph classification**: one label per graph (is this molecule toxic?), by **pooling** node representations (sum or mean, or learned hierarchical pooling) into a graph vector.

## What the lab shows

**Graph and features are complementary.** A stochastic block model: 600 nodes in 4 communities, 76% of edges inside a community, node features that are informative but noisy, and 20 labeled nodes per class. Features alone (an MLP) get 0.87; the graph alone (label propagation, which spreads the known labels along edges) gets 0.93; a two-layer GCN with both gets 0.996.

**Over-smoothing.** Each GCN layer averages a node with its neighbors, so each layer is a step of a random walk on the graph (the operator behind spectral embeddings, 21.4): stack enough and every node in a connected component converges to the same vector. In the lab, without residual connections:

| layers | 2 | 4 | 8 | 16 | 32 |
|---|---|---|---|---|---|
| accuracy | 1.00 | 0.99 | 0.96 | 0.24 | 0.26 |
| mean cosine between random nodes' vectors | 0.43 | 0.49 | 0.52 | 1.00 | 1.00 |

With residual connections, 32 layers still gets 0.97 (cosine 0.86, rising but not collapsed). Two honest caveats. Part of the failure of deep plain GCNs is ordinary trainability (a 32-layer network without residuals, 26.2 and 26.4), not only smoothing; the two effects are entangled, and the literature argues about the split. And most practical GNNs are shallow, 2 to 4 layers, because most useful information is local and deeper models cost more without helping. If you need long-range information, residuals, jumping knowledge (concatenate all layers' outputs) or a graph transformer with global attention are the usual answers.

**Heterophily.** GCN's averaging assumes that neighbors are similar (**homophily**). Where edges mostly connect *different* kinds of nodes (fraudsters transact with victims, not other fraudsters; proteins interact with complementary partners), averaging mixes a node's features with the wrong class. In the lab's heterophilic graph (6% of edges within a class), the GCN gets 0.62 and loses to the MLP that ignores the graph (0.75). GraphSAGE, which keeps the node's own features in a separate channel, gets 0.86, better than either: it can learn that "my neighbors look like class A" means "I'm probably not A". Check homophily before you pick an architecture; it's one line of code.

## Limits of message passing

- **Expressiveness**: message passing GNNs can't distinguish graphs that the 1-dimensional Weisfeiler-Lehman test can't (Xu et al., 2019; Morris et al., 2019). Two triangles and a hexagon, where every node has degree 2, look identical to them. Adding node identifiers, random features, or structural features such as cycle counts breaks the symmetry.
- **Over-squashing**: information from an exponentially growing neighborhood has to fit through fixed-size vectors along bottleneck edges (Alon and Yahav, 2021), so long-range dependencies are hard to learn, separately from over-smoothing.
- **Scale**: full-graph training needs the whole adjacency and all activations in memory; large graphs use neighbor sampling (GraphSAGE), cluster-based batching (Cluster-GCN), or precomputed propagated features (SIGN).

## In practice

- **Start with features plus a gradient-boosted model** (20.4): node degree, neighbor label rates (computed without leaking the target, 18.4), PageRank, community IDs. It's often competitive and much easier to explain.
- Then try a GNN: **PyTorch Geometric** or **DGL**, a 2-layer GCN or GraphSAGE as the baseline, a GAT if neighbor importance varies.
- **Splits**: random node splits leak information through edges between train and test nodes, which is usually fine for transductive tasks and wrong if the model will face new, unconnected nodes or a future graph. Split by time for anything that evolves (fraud, social networks): train on the graph as it was, test on nodes that appeared later.
- **Adversarial robustness**: an attacker who can add edges (create accounts, send transactions to a target, link to a domain) can move a GNN's predictions for nodes they don't control (Zügner, Akbarnejad and Günnemann, 2018). If your graph is built from untrusted actions, which in fraud and abuse it always is, assume someone is shaping it (53.1).
- Molecules and materials have their own specialized architectures that respect 3D symmetry (equivariant GNNs, and AlphaFold's structure module is a relative); they're a field of their own.

## Things that will bite you

- **Heterophilic graphs with a GCN**: worse than ignoring the graph.
- **Too many layers**: over-smoothing, and cost.
- **Leakage through edges** in the train/test split, or through label-derived node features.
- **Degree effects**: high-degree nodes dominate sums; isolated nodes get no neighborhood signal at all.
- **Transductive evaluation for an inductive deployment**.
- **Graphs built from attacker-controlled actions**, evaluated as if nobody were adversarial.

2. A node's neighbors have no natural order: node IDs are arbitrary, and the same neighborhood listed in a different order must produce the same result. An order-dependent aggregator (concatenation, an RNN over neighbors) would make the output depend on the numbering, which is meaningless and doesn't generalize. Permutation-invariant aggregation makes each layer permutation equivariant.

3. Nodes within 3 hops of $v$ (its 3-hop neighborhood, including $v$ via the self-loops). Nodes further away have no path of length at most 3 to $v$, so their features can't reach it.

4. Each GCN layer replaces a node's representation with a normalized average over itself and its neighbors (after a linear map). Repeated averaging over a connected graph is a random walk that converges to its stationary distribution: all nodes in a component tend toward the same vector (up to degree scaling), so they become indistinguishable. A residual connection adds the node's previous representation back at each layer, so its own signal isn't averaged away; the output mixes local and propagated information.

5. The GCN averages each node with its neighbors, most of which (94% of edges) belong to other classes, so its features are diluted with the wrong classes' features. The MLP uses only the node's own noisy features. GraphSAGE uses both, in separate channels: the node's own features, and a summary of its neighbors, which is informative in reverse (if my neighbors look like class A, I'm likely not A). It can learn that relation, which neither of the others can.
