# Part IV: Deep Learning

From a single neuron to transformers, diffusion models and multi-GPU training. You will build an autograd engine yourself before you are allowed to touch PyTorch, because after that PyTorch stops being magic.

About 295 hours in total.

| Module | Hours | What it's about |
|---|---|---|
| [24. Neural Networks from Scratch](24-neural-nets-from-scratch/) | 30 | No frameworks. Just NumPy, the chain rule and stubbornness. |
| [25. PyTorch](25-pytorch/) | 25 | The framework, properly. Not the tutorial, the framework. |
| [26. Training Deep Networks](26-training-deep-networks/) | 40 | Why the same architecture trains beautifully for one person and diverges for another. |
| [27. Computer Vision](27-computer-vision/) | 45 | Pixels in, decisions out. |
| [28. Sequence Models](28-sequence-models/) | 20 | Before transformers ate the world. Still worth knowing, for history and for streaming problems. |
| [29. Transformers](29-transformers/) | 35 | The architecture behind almost everything interesting since 2017, built from the ground up. |
| [30. Representation Learning](30-representation-learning/) | 20 | Learning useful features without labels, and connecting images to text. |
| [31. Generative Models](31-generative-models/) | 40 | Teaching machines to make things, and understanding the math instead of just the pretty samples. |
| [32. Graph Neural Networks](32-graph-neural-networks/) | 10 | For data that is a network, not a table or a grid. |
| [33. Deep Learning at Scale](33-dl-at-scale/) | 30 | What changes when the model doesn't fit on one GPU and the bill has six digits. |
