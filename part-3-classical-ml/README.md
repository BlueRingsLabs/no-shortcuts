# Part III: Classical Machine Learning

Statistical learning, derived and implemented from scratch, then used properly with scikit-learn. Most ML in production is still this, and anybody who tells you otherwise has never had to explain a model to an auditor.

About 245 hours in total.

| Module | Hours | What it's about |
|---|---|---|

| [17. Linear Models](17-linear-models/) | 35 | The most underrated models in the business. Also the gateway to neural networks. |
| [18. Evaluation](18-evaluation/) | 30 | The module that protects you from your own optimism. |
| [19. Instance, Probabilistic and Kernel Methods](19-instance-kernel-probabilistic/) | 25 | Three families of classic models, each with an idea you will see again in deep learning. |
| [20. Trees and Ensembles](20-trees-ensembles/) | 35 | If your data lives in a table, this is probably the module that pays your salary. |
| [21. Unsupervised Learning](21-unsupervised/) | 30 | Finding structure when nobody gave you labels. Also finding structure that isn't there, if you're careless. |
| [22. The Practical Workflow](22-practical-workflow/) | 25 | How the pieces fit together in a real project. |
| [23. Applied Domains](23-applied-domains/) | 40 | Four kinds of problems that show up in real jobs constantly and in toy courses almost never. |
